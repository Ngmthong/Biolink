# Mthongiosvn Bio

Bio page hiện đại cho **Thế Giới Đồ Chơi Mthongiosvn**.

## Cấu trúc
- `index.html` — trang Bio chính
- `assets/avatar.jpg` — avatar
- `assets/music.mp3` — nhạc nền

## Đưa lên GitHub Pages
1. Tạo một repository mới trên GitHub.
2. Upload **toàn bộ** thư mục này, giữ nguyên thư mục `assets`.
3. Vào **Settings → Pages**.
4. Chọn branch chứa `index.html` và thư mục `/root`.
5. Lưu lại và mở URL GitHub Pages.

## Chức năng
- Facebook / Telegram / Zalo mở trực tiếp.
- Nhạc: Phát / Dừng / Âm lượng / Lặp.
- Chuyển sáng/tối và lưu lựa chọn.
- Chia sẻ: Web Share hoặc sao chép link khi trình duyệt hỗ trợ.
- Tìm kiếm game/liên hệ.
- Menu dưới: Trang chủ / Liên hệ / Nhạc / Lên đầu.
- Tối ưu mobile.

### Lưu ý nhạc
Trình duyệt điện thoại thường chặn **autoplay**. Người dùng cần bấm `▶ PHÁT` một lần; đây là giới hạn bảo mật của trình duyệt, không phải lỗi của trang.
